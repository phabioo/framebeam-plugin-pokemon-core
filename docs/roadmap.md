# Roadmap

Status: in progress: skeleton and ORAS adapter. Depends on FrameBeam plugin API v1 (0.11, planned); see https://github.com/phabioo/framebeam `docs/roadmap.md`.

## v0.1 Omega Ruby / Alpha Sapphire (3DS, Gen 6)

- Game detection by title ID, German/EU release first, German and English at least; detect the active game language at runtime (3DS system language), never assume it.
- Adapters: team, boxes, location, battle state, encounters, badges; PKM decryption/shuffle (Gen 6) with synthetic fixtures generated by code.
- Asset extraction from the player's own game files into the local plugin cache (box icons, sprites, region map); nothing is stored in this repository.
- Location/route table keyed by internal IDs, with self-recorded map coordinates; `provides` interface for other plugins.
- Offsets documented per game in `docs/games/<game>.md`; verified locally by the maintainer with the FrameBeam developer mode.

## Later

1. Gen 7 (Sun/Moon, Ultra Sun/Ultra Moon): same 3DS formats, small step.
2. Gen 4 and 5 (NDS): NARC/NCGR containers, Gen 4/5 PKM.
3. Gen 3 (GBA) and Gen 1/2 (GB/GBC): need the GB, GBC and GBA systems in FrameBeam first.

Gen 8 / Switch is out of scope. Requires plugin API v1 (FrameBeam 0.11, planned).
